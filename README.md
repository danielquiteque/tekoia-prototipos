# Protótipos TekoIA

Dois protótipos de letramento crítico em IA para jovens e educadores, feitos por Daniel Quiteque.

- **A IA conhece o meu território?** (`oficina-territorio.html`): apostila interativa de uma oficina de 3 horas.
- **Mentor do Território** (`mentor-territorio.html`): educação empreendedora com IA que pergunta mais do que responde.

A geração com IA ao vivo funciona na versão hospedada no claude.ai. No GitHub Pages as páginas mostram o fluxo com exemplos.
